# Marie Curie Tribute Page

<img width="1902" height="907" alt="image" src="https://github.com/user-attachments/assets/d05c5b2c-60ef-47f4-a81b-bf7985cec3af" />


A responsive tribute page dedicated to Marie Curie, the pioneering physicist and chemist whose research transformed the study of radioactivity.

## Features

- Editorial-style hero section with Marie Curie's name and tagline
- Responsive layout for desktop and mobile screens
- Original biographical tribute content
- Timeline of key achievements from 1891 to 1914
- Distinctive quote section
- Wikimedia Commons portrait image
- Playfair Display serif headings paired with DM Sans body text
- Multiple background colors and subtle entrance animation
- Accessible navigation, image alt text, and semantic HTML structure

## How to View

No build tools or dependencies are required.

1. Open `index.html` in a web browser.
2. For the best experience, use a local server such as the VS Code Live Server extension.

The page loads its fonts from Google Fonts and its portrait from Wikimedia Commons, so an internet connection is needed for those external assets.
